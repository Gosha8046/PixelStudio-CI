# Следующий этап (за пределами MVP)

Здесь перечислено то, чего **нет** в текущей версии. В коде под эти функции нет заглушек: каждая будет добавлена целиком, вместе с тестами.

## 1. Скелетная анимация

- **Модель:** `Skeleton { Bones[] }`, где `Bone { Id, ParentId, Length, BindPose(x, y, rotation) }`. К кости привязываются **части спрайта**: отдельные слои или вырезанные области с точкой вращения (pivot).
- **Анимация:** ключевые кадры трансформаций костей (`Track<BoneId, Keyframe{time, rotation, translation, scale}>`), интерполяция linear/step/bezier, отдельный таймлайн в миллисекундах. Он не заменяет покадровый, а живёт рядом с ним.
- **Пиксельная точность:** повёрнутые части растеризуются nearest-neighbour с опциональным алгоритмом RotSprite, чтобы контур не «размывался». Есть режим запекания (bake) скелетной анимации в обычные кадры. Тогда результат проходит через существующий экспорт спрайтшита.
- **Экспорт:** либо запечённые кадры (работают везде), либо отдельный JSON с иерархией костей. Второй вариант потребует импортёров для движков (см. п. 4).

## 2. Пользовательские текстуры курсора

- Формат курсора: PNG до 32×32 + hotspot `(x, y)`. Набор курсоров на инструмент хранится в настройках приложения, не в проекте.
- В браузере: CSS `cursor: url(data:image/png...) x y, crosshair`. В WebView2 — то же самое. Нужно учесть ограничения браузеров на размер курсора и масштабирование при `devicePixelRatio` ≠ 1.
- Режим «курсор как кисть»: предпросмотр отпечатка инструмента прямо на overlay-холсте. Он уже рисует Pixel Crosshair, так что инфраструктура готова.

## 3. Продвинутая упаковка атласов

- Обрезка прозрачных краёв (trim) с сохранением `sourceSize` и `spriteSourceSize`, чтобы движок восстановил исходную позицию.
- Упаковка MaxRects / Skyline вместо сетки, опциональный поворот на 90° (`rotated: true`), extrude краёв на 1 px против «протечек» при фильтрации, padding и размеры кратные степени двойки.
- Дедупликация одинаковых кадров: несколько кадров ссылаются на один прямоугольник.
- Несколько анимаций (тегов) в одном атласе: `animations: [{ name, from, to, direction }]`.
- Формат JSON версии 2 с обратной совместимостью: старое поле `frames[]` остаётся.

## 4. Импортирующие скрипты для игровых движков

Универсальный JSON остаётся источником данных, адаптеры живут в отдельной папке `engine-importers/` со своими тестами:

| Движок | Адаптер | Что делает |
|---|---|---|
| Unity | `ScriptedImporter` для `.pxsheet.json` (Editor) | Режет Texture2D на Sprite'ы (с пересчётом Y снизу вверх), создаёт `AnimationClip` с ключами по `durationMs` и loop-флагом |
| Godot 4 | `EditorImportPlugin` (GDScript) | Создаёт ресурс `SpriteFrames` с `AtlasTexture` для каждого кадра и относительными длительностями |
| Unreal Engine 5 | Python-скрипт Editor Scripting или конвертер в формат импорта sprite sheet для Paper2D | Создаёт `PaperSprite` по прямоугольникам и `PaperFlipbook` с длительностями |

Каждый адаптер проверяется на эталонном экспорте из `docs/examples/` в CI. Для этого нужны образы с движками; это отдельная задача инфраструктуры.

## 5. Выделение и трансформация

- Инструменты: прямоугольное выделение, лассо, «волшебная палочка» (переиспользует сопоставление цветов из заливки), выделить всё / инвертировать.
- Маска выделения — `bool[]`/битовая карта размера холста. Инструменты рисования учитывают маску.
- Перемещение выделения с «плавающим» фрагментом. Поворот на 90°/180°, отражения по горизонтали и вертикали без потерь. Произвольный поворот и масштаб через nearest-neighbour / RotSprite.
- Буфер обмена: копирование и вставка между слоями и кадрами, а в браузере — через Clipboard API (только по жесту пользователя).
- Undo: каждая трансформация — один `PixelEditCommand` (или группа команд для нескольких cel'ов).

## Прочее, что сознательно отложено

- Кисти больше 1 px, линии и фигуры, симметрия, dithering.
- Импорт PNG и GIF, экспорт GIF и APNG.
- Изменение размера холста существующего проекта.
- Бесшовное рисование через границы тайла в Tile Preview (сейчас это режим просмотра).
- File System Access API в Chromium для «настоящего» сохранения в тот же файл в браузере.
- Перетаскивание кадров и слоёв мышью (сейчас перестановка кнопками).
- Подписание Windows-сборки (code signing) и установщик MSIX.
