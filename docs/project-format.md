# Формат проекта `.pxstudio` (версия 1)

Проект хранится как JSON-файл в кодировке UTF-8. Формат читаем человеком, легко сравнивается в diff и детерминирован: повторное сохранение загруженного проекта даёт байт-в-байт тот же файл (это проверяет тест).

```json
{
  "format": "PixelStudioProject",
  "formatVersion": 1,
  "generator": "PixelStudio CI 0.1.0",
  "width": 16,
  "height": 16,
  "fps": 8,
  "loop": true,
  "palette": ["#1A1C2CFF", "#5D275DFF"],
  "layers": [
    { "id": 1, "name": "Слой 1", "visible": true, "opacity": 100, "blendMode": "Normal" },
    { "id": 2, "name": "Тень", "visible": true, "opacity": 60, "blendMode": "Multiply" }
  ],
  "frames": [
    {
      "id": 3,
      "durationMs": null,
      "cels": [
        { "layerId": 1, "encoding": "rgba8-zlib-base64", "data": "eNrt…" },
        { "layerId": 2, "encoding": "rgba8-zlib-base64", "data": "eNpj…" }
      ]
    }
  ]
}
```

| Поле | Правила |
|---|---|
| `format` | Строго `"PixelStudioProject"` |
| `formatVersion` | Целое число. Сейчас `1`. Если файл новее приложения, выводится сообщение «обновите приложение» |
| `width`, `height` | 1–512 |
| `fps` | 1–60. Кадр без своей длительности длится `round(1000 / fps)` мс |
| `loop` | Зацикливание анимации |
| `palette` | До 64 цветов `#RRGGBBAA` |
| `layers` | 1–64 слоя, **снизу вверх**. `id` уникален в пределах файла; `opacity` — целое 0–100 (%); `blendMode` — `Normal` / `Multiply` / `Screen` |
| `frames` | 1–256 кадров в порядке таймлайна; `durationMs` — `null` (по FPS) или 1–60000 |
| `cels` | Пиксели слоя в кадре: `width·height` пикселей RGBA8 (прямая, не премультиплицированная альфа), построчно сверху вниз, сжатые zlib (RFC 1950) и закодированные в Base64 |

Отсутствующий cel означает полностью прозрачный слой в этом кадре. Сохранение всегда записывает все cel'ы.

## Проверки при открытии

Файл не открывается, а пользователь получает понятное сообщение на русском, если:

- файл пустой или больше 64 МБ;
- JSON некорректен (сообщение содержит номер строки и позицию);
- `format` не тот («Это не проект PixelStudio…»);
- версия формата новее поддерживаемой или меньше 1;
- размеры, FPS, число слоёв или кадров, прозрачность, длительности или цвета палитры выходят за пределы допустимого;
- встречаются повторяющиеся `id`, ссылки на несуществующий слой, неизвестная кодировка или режим смешивания;
- пиксельные данные повреждены: битый Base64 или zlib, лишние или недостающие байты.

Распаковка ограничена ожидаемым размером `width·height·4`, поэтому «zip-бомба» не раздует память. Открытие сначала полностью проверяет файл, и только потом заменяет текущий документ. Если файл битый, открытый проект остаётся нетронутым.

## Эволюция формата

При несовместимых изменениях `formatVersion` увеличивается. В `ProjectSerializer.Load` предусмотрено место для миграций старых версий. Неизвестные поля новых версий игнорируются, но только если номер версии не изменился.
